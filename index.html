Ground Up C++

C++ from your first line to engines, kernels and trading systems

A textbook for people who know a little Python and nothing about C++. It goes from int main() to memory, modern C++, performance, a game engine, a renderer, a machine-learning library, GPU kernels and a low-latency matching engine. Every example was compiled and run, and every output is real.

Start readingJump to the basicsSee the projects
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v{3, 1, 4, 1, 5};
    long sum = 0;
    for (int x : v) sum += x;   // a few CPU instructions
    std::cout << "sum = " << sum << '\n';
}

$ g++ -std=c++23 -O2 main.cpp -o main && ./main
sum = 14
